# HH Agent (v1.1.0 Stable)

Графическое приложение-оболочка (GUI) для автоматизации откликов на вакансии HeadHunter, построенное поверх популярной консольной утилиты `hh-applicant-tool`. 

Приложение предназначено для обычных пользователей, которые не хотят разбираться с командной строкой, JSON-конфигами и установкой Python, но хотят получить мощный инструмент для массовой рассылки резюме.

**Лицензия:** Приложение распространяется АБСОЛЮТНО БЕСПЛАТНО для некоммерческого использования.

---

## 🔥 Ключевые возможности (Что нового в v1.1.0)

* **Графический интерфейс (GUI):** Интуитивно понятный мастер настройки (Wizard), где все параметры настраиваются кликом мыши.
* **Smart Launcher (Умное ядро):** При первом запуске приложение само скачивает последнюю версию консольного ядра `hh-applicant-tool` из GitHub. Ядро обновляется динамически — вам больше не нужно скачивать новые версии `HH-Agent.exe` при каждом изменении API HeadHunter.
* **Тёмная тема (Dark Mode):** Полноценная поддержка тёмной темы интерфейса для комфортной работы ночью. Настройки сохраняются автоматически.
* **Интеграция с Telegram:** Теперь Telegram-бот работает в фоне основного приложения! Он не только присылает уведомления (и предупреждает о капче), но и позволяет **полностью управлять рассылкой с телефона**: запускать отклики, останавливать процесс, поднимать резюме, получать статистику ЗП и настраивать стоп-слова.
* **Spintax в сопроводительных письмах:** Поддержка синтаксиса `{Привет|Здравствуйте}` для рандомизации текста откликов, чтобы избежать спам-фильтров.
* **Мультиаккаунт (Профили):** Легко импортируйте профили из старых сборок Telegram-ботов или создавайте новые. Поддерживается переключение между резюме.
* **Встроенный браузер (Playwright):** Для авторизации и прохождения проверок на человечность используется полноценный встроенный браузер Chromium.
* **Никакой телеметрии:** Приложение сохраняет ваши токены, логи и настройки строго локально на вашем компьютере (в папке `%APPDATA%\HH_Agent`).

## 📥 Инструкция по запуску

1. Перейдите на вкладку **Releases** и скачайте актуальную сборку `HH-Agent.exe` (v1.1.0).
2. Поместите скачанный `.exe` файл в любую удобную папку на вашем ПК (желательно не на Рабочий стол и не в системные папки, так как рядом может быть создана папка `data`, хотя по умолчанию все данные лежат в `%APPDATA%`).
3. Запустите `HH-Agent.exe`.
4. *Важно:* При первом запуске (если у вас Windows 10/11) может сработать защита **Windows SmartScreen** с предупреждением "Система Windows защитила ваш компьютер". Это нормально для бесплатных приложений без платной цифровой подписи (EV сертификата). Нажмите **"Подробнее"**, а затем **"Выполнить в любом случае"**.
5. Дождитесь, пока Smart Launcher скачает ядро и браузер Chromium (это займет пару минут).
6. Пройдите авторизацию через браузер, настройте фильтры и запустите рассылку!

## 🛠 Для разработчиков

Для самостоятельной сборки приложения требуется Python 3.10+ и ОС Windows.

1. Склонируйте репозиторий.
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Для сборки exe-файла запустите скрипт `build.bat` (он автоматически вызывает PyInstaller с правильной конфигурацией `hh_agent.spec` и подтягивает нужные стандартные библиотеки, скрытые от динамического ядра).
4. Готовый билд появится в папке `dist`.
