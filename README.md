# HH Agent (v1.2.2)

Графическая оболочка (GUI) для автоматизации откликов на вакансии HeadHunter поверх консольной утилиты [`hh-applicant-tool`](https://pypi.org/project/hh-applicant-tool/).

Приложение для тех, кто не хочет разбираться с командной строкой, JSON-конфигами и установкой Python, но хочет массово рассылать отклики.

**Лицензия:** бесплатно для некоммерческого использования.

---

## Ключевые возможности

* **Графический интерфейс.** Мастер первого запуска, настройка фильтров мышью, живая лента прогона и отчёты.
* **Smart Launcher.** Консольное ядро `hh-applicant-tool` не входит в `.exe` — приложение скачивает его с PyPI при первом запуске. Версия ядра задаётся файлом `remote_config.json` в этом репозитории, поэтому исправление под изменившийся API HH доезжает до пользователей без пересборки `.exe`.
* **Тёмная тема.** Переключатель-иконка в шапке, выбор запоминается.
* **Telegram-бот.** Работает в фоне основного приложения: уведомления о старте/финише прогона и о капче, запуск рассылки, пингов и чистки отказов с телефона, поднятие резюме, топ вакансий по зарплате, редактирование стоп-слов (`+ слово` / `- слово`).
* **Spintax.** Синтаксис `{Привет|Здравствуйте}` в сопроводительных письмах и пингах, с проверкой шаблона до запуска рассылки и подсчётом числа вариантов.
* **Пинги без повторов.** В один и тот же чат не уйдёт дважды один и тот же текст.
* **Стоп-слова по названию вакансии.** Со стеммингом: «продажи» ловит «менеджер по продажам», но не режет вакансию из-за слова в описании.
* **Выбор резюме.** Вкладка «Резюме» показывает всё, что отдаёт hh.ru — статус публикации, дату обновления, просмотры — и позволяет выбрать, с каким резюме рассылать отклики (или оставить «все»).
* **Мультиаккаунт (профили).** Список аккаунтов с отметкой входа, переключение в один клик, удаление — из списка или вместе с данными. Импорт профилей из старых сборок Telegram-ботов.
* **Встроенный браузер (Playwright Chromium)** для авторизации и прохождения проверок.
* **Никакой телеметрии.** Токены, логи и настройки остаются на вашем компьютере.

## Установка и запуск

1. Скачайте `HH-Agent.exe` со вкладки **Releases**.
2. Положите файл в отдельную папку — **рядом с ним создаётся папка `data`** с профилями, базой и отчётами. Не кладите `.exe` на Рабочий стол и в системные папки.
3. Запустите. Windows SmartScreen может показать «Система Windows защитила ваш компьютер» — это нормально для приложения без платной подписи кода: **Подробнее → Выполнить в любом случае**.
4. При первом запуске откроется окно загрузчика: приложение скачает ядро, потом — Chromium. Это занимает пару минут и делается один раз.
5. Пройдите авторизацию на hh.ru через встроенный браузер, напишите сопроводительное письмо, настройте фильтры и запускайте рассылку.

### macOS

1. Скачайте образ под свой процессор: **`HH-Agent-arm64.dmg`** — Apple Silicon (M1 и новее), **`HH-Agent-intel.dmg`** — маки на Intel. Узнать процессор: меню  → «Об этом Mac», строка «Чип» или «Процессор».
2. Откройте `.dmg` и перетащите **HH-Agent** в «Программы».
3. Первый запуск: приложение без платной подписи Apple, поэтому macOS скажет, что не может проверить разработчика. На macOS 15 и новее: **Системные настройки → Конфиденциальность и безопасность → внизу «HH-Agent» → «Всё равно открыть»**. На macOS 14 и старше достаточно правого клика по приложению → «Открыть».
   Если macOS пишет, что приложение «повреждено», снимите с него карантин в Терминале: `xattr -dr com.apple.quarantine /Applications/HH-Agent.app`.
4. Дальше — как на Windows: загрузчик скачает ядро и браузер, затем мастер настройки.

### Где лежат данные

| Что | Где |
|---|---|
| Профили, `config.json`, база SQLite, куки, отчёты, логи | папка `data` **рядом с `HH-Agent.exe`** |
| Консольное ядро `hh_applicant_tool` | `%APPDATA%\HH_Agent\core` |
| Браузер Chromium | `%LOCALAPPDATA%\ms-playwright` |

Приложение портативное: чтобы перенести всё на другой компьютер, скопируйте `.exe` вместе с папкой `data`.

На macOS всё лежит вне приложения — его можно обновлять заменой `HH-Agent.app`, профили не пропадут:

| Что | Где |
|---|---|
| Профили, база, куки, отчёты, логи, `selftest.log` | `~/Library/Application Support/HH_Agent/data` (логи — уровнем выше) |
| Консольное ядро | `~/Library/Application Support/HH_Agent/core` |
| Браузер | `~/.cache/ms-playwright` |

Селф-тест на маке: `/Applications/HH-Agent.app/Contents/MacOS/HH-Agent --selftest`.

## Диагностика

```
HH-Agent.exe --selftest
```

Пишет отчёт в консоль и в `selftest.log` рядом с `.exe`: какие модули доехали в сборку, совместимо ли скачанное ядро, на месте ли Chromium и шаблоны. Работает и до установки ядра — именно для того, чтобы объяснить, почему ядро не встало.

Другие ключи: `--wizard` (открыть мастер заново), `--debug` (DevTools в окне), `--install-browser` (служебный, вызывается мастером).

## Для разработчиков

Требуется **Python 3.11+** (ядро `hh-applicant-tool` объявляет `Requires-Python >=3.11,<4.0`). `.exe` собирается на Windows, `.app` — на macOS, причём под архитектуру того мака, где идёт сборка (arm64 на Apple Silicon, x86_64 на Intel).

```bash
git clone https://github.com/ganjadrugdealer-prog/HH_Agent.git
cd HH_Agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Прогон проверок (ставит ядро и гоняет функциональные тесты):

```bash
python tools/ci_check.py
```

Или отдельно, если ядро уже установлено:

```bash
pip install hh-applicant-tool==1.8.28
python tools/selfcheck.py
```

Сборка `.exe`:

```bash
build.bat          # или: python build.py
```

Готовый файл — в папке `dist`.

На macOS (системный `python3` там 3.9 — нужен отдельный 3.11+):

```bash
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python tools/ci_check.py
sips -s format icns icon.png --out icon.icns
.venv/bin/python build.py
dist/HH-Agent.app/Contents/MacOS/HH-Agent --selftest
```

### Как устроен проект

| Файл | Зачем |
|---|---|
| `app_main.py` | Точка входа, окно загрузчика, селф-тест, служебные режимы |
| `core_manager.py` | Скачивание и подключение ядра `hh-applicant-tool` |
| `app_api.py` | JS API для интерфейса (наследует штатный `Api` ядра) |
| `engine.py` | **Единственный** модуль, знающий флаги и операции ядра; `check()` ловит переименования флагов до сборки |
| `hh_patch.py` | Правки поведения ядра: стоп-слова по названию, dry-run без чёрного списка, случайная пауза, окно входа, пинги без повторов, безопасные типы SQLite |
| `letters.py` | Spintax: разворот, проверка, подсчёт вариантов, память по чатам |
| `stopwords.py` | Список слов → регулярка со стеммингом |
| `run_monitor.py` | Разбор вывода ядра в события, лента прогона, отчёты |
| `profiles.py` | Несколько аккаунтов hh.ru в одной установке |
| `telegram_bot.py` | Управление с телефона |
| `tools/selfcheck.py` | Функциональные тесты всего перечисленного |
| `ui/app.html` | Интерфейс: главная, письма, резюме, поиск, отклики, настройки |

Флаги ядра меняются от версии к версии. Если ядро обновилось — правьте только `engine.py`, а затем прогоните `tools/selfcheck.py`: тест `engine_argv_accepted_by_core` реально скармливает собранный `argv` парсеру ядра.
