# HH Agent

**HH Agent** — это десктопное приложение для автоматизации поиска работы и откликов на вакансии на сайте HeadHunter (hh.ru). Приложение работает как умный ассистент, помогая массово откликаться на релевантные вакансии, обходить спам-фильтры и напоминать о себе рекрутерам.

Проект является графической оболочкой (GUI) и расширением для консольного движка `hh-applicant-tool`, предоставляя удобный интерфейс, портативность и дополнительные функции, делающие поведение бота более человечным.

## ✨ Ключевые возможности

* **Умная рассылка откликов (Smart Auto-apply):** Автоматический поиск вакансий по заданным фильтрам (зарплата, регион, удаленка) и отправка откликов.
* **Уникальные сопроводительные письма (Spintax):** Поддержка спинтакса (например, `{Здравствуйте|Добрый день}`) и переменных (`%(first_name)s`, `%(vacancy_name)s`). Бот генерирует тысячи уникальных вариантов писем, снижая риск блокировки за спам.
* **Умный фильтр стоп-слов:** В отличие от базового движка, фильтрация по стоп-словам применяется *только к названию вакансии*. Это предотвращает пропуск хороших вакансий из-за случайного упоминания стоп-слова в длинном описании.
* **Пинги (Follow-ups):** Автоматическая рассылка напоминаний в активные чаты с работодателями, если они долго не отвечают. Система запоминает отправленные сообщения (`ping_memory.json`) и гарантирует, что в один чат никогда не уйдет два одинаковых сообщения.
* **Многопрофильность:** Поддержка нескольких аккаунтов hh.ru. Идеально подходит для ведения разных профилей, данные которых изолированы друг от друга.
* **Человекоподобное поведение:** Случайные задержки между запросами к API и использование Playwright (эмуляция реального браузера) для безопасной авторизации.
* **Интеграция с Telegram:** Отправка отчетов о результатах рассылки и уведомлений прямо в вашего Telegram-бота.
* **Автоподнятие резюме:** Функция автоматического поднятия вашего резюме в поиске каждые 4 часа.
* **Очистка отказов:** Автоматическое скрытие и архивация отказов, чтобы не засорять список активных откликов.
* **Портативность:** Приложение собирается в один exe-файл, не требует сложной установки и хранит все данные локально в папке `data`.

## 🚀 Установка и запуск

1. Скачайте последнюю версию `HH-Agent.exe` из раздела [Releases](#) (или соберите самостоятельно).
2. Поместите исполняемый файл в отдельную пустую папку (рядом с ним будет создана папка `data` для хранения базы данных, логов и профилей).
3. Запустите `HH-Agent.exe`.
4. При первом запуске откроется **Мастер настройки**:
   * Приложение автоматически скачает необходимый браузер (Chromium через Playwright) для обхода защит авторизации.
   * Вы сможете настроить интеграцию с Telegram (опционально).
   * Необходимо будет авторизоваться в свой аккаунт hh.ru (в безопасном окне встроенного браузера).
   * Мастер предложит составить базовый шаблон сопроводительного письма с использованием спинтакса.

## 🛠 Сборка из исходников

Для самостоятельной сборки потребуется Python 3.9+ и установленный менеджер пакетов.

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Для сборки exe-файла используйте скрипт `build.bat` (или PyInstaller с конфигурацией из `hh_agent.spec`).
4. Готовый исполняемый файл появится в папке `dist`.

## ⚙️ Настройка поиска

В основном интерфейсе приложения вы можете гибко настроить параметры:
* **Стоп-слова:** Список слов, при наличии которых в названии вакансии отклик отправлен не будет.
* **Зарплата:** Минимальная желаемая ЗП.
* **Формат работы:** Галочка для поиска только удаленной работы.
* **Лимиты:** Ограничение на количество откликов в день или за один прогон.
* **Холостой прогон (Dry Run):** Тестовый режим, который собирает статистику и показывает, куда бы бот откликнулся, но не совершает реальных действий.
